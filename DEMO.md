## Верные варианты одиночного выбора

Форма собирается случайно, поэтому ниже весь банк Backend · Middle, а не один билет.

- Списание денег оборвалось посередине — атомарность
- Повтор того же PUT — то же состояние, что после первого успеха
- Индекс — ускорить поиск по ключу
- Объекта нет — 404
- N+1 — один запрос списка и запрос на каждую строку
- Пул соединений — переиспользовать уже открытые
- Дубль почты — уникальное ограничение в базе
- Глубокий OFFSET — дорогой и сдвигается при вставках
- JWT access — подпись проверяется без записи каждого токена
- Два процесса записали 110 — потерянное обновление
- Outbox — событие не теряется, если брокер недоступен
- Ограничение скорости потребителя — чтобы не копить бесконечный хвост
